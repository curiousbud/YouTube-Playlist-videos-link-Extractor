# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| Latest  | ✅ Fully Supported |
| Older   | ❌ No Support      |

Please ensure you are using the latest version to benefit from security updates.

---

## Reporting a Vulnerability

We take the security of our project seriously. If you discover a vulnerability, please follow these steps:

1. **Contact Us Directly**
   - Email: [akareeb662@gmail.com](mailto:akareeb662@gmail.com)  
   - Or, open a [private security advisory](https://github.com/curiousbud/YouTube-Playlist-videos-link-Extractor/security/advisories/new).

2. **Provide Necessary Details**
   Include:
   - A detailed description of the issue.
   - Steps to reproduce the vulnerability.
   - Any potential impact of the vulnerability.

3. **Our Response**
   - We will acknowledge receipt within **5 business days**.
   - We will investigate and resolve the issue promptly.
   - Once resolved, we will disclose the details responsibly.

---

## Security Best Practices

We recommend users:
- Use the latest version of the tool.
- Avoid sharing sensitive API keys or credentials.
- Regularly review and update dependencies.
